# Security

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/seapagan/labeldeck/security/advisories/new).
Use the repository's **Security** tab and select **Report a vulnerability**.
Do not put sensitive vulnerability details in a public issue or pull request.

Include the affected labeldeck version or commit, operating system, reproduction
steps, and expected impact. Use a test repository and dummy credentials for
examples. Remove GitHub tokens, authorization headers, and private repository
data from logs, screenshots, and files before attaching them.

If you exposed a token, revoke it through GitHub. See the README's
[authentication guidance](README.md#authentication) for token permissions and
storage details.
